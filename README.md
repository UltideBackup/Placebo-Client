## ClickGUI

The client ships with a **native monochrome ClickGUI** rendered using Minecraft's built-in `GuiGraphics` API. No MCEF, no browser, no external dependencies — just `fill()` and `drawString()` calls.

* Default keybind: **Right-Shift** (rebindable in Controls → Placebo Client)
* Pure black/grey/white palette — 11 ink shades, zero accent color
* Draggable category panels with positions persisted to `~/.placebo/clickgui.properties`
* Search bar at the top that filters modules across all 169 modules
* Smooth animations — hover/toggle/expand all lerp toward their target every frame
* Module toggle indicator: small dot on the right + colored bar on the left edge
* Status bar at the bottom showing module count + enabled count
* Right-shift to toggle, drag panels to move, type to search, ESC to close

### Why native instead of MCEF?

Because MCEF was a fucking nightmare to wire up — version mismatches, broken dependencies, 700MB downloads. The native UI is ~600 lines of Kotlin, builds in 30 seconds, and runs everywhere MC 26.2 runs. No browser required.

## Build Instructions

### Prerequisites

- **JDK 25** (the project targets `--release 25`). Check with `java -version` — it should print `version 25` (or `25.x.x`). If it doesn't, install Temurin JDK 25 from [adoptium.net](https://adoptium.net/) and set `JAVA_HOME` to the install path.
- **Internet access** (Gradle downloads Minecraft + Fabric on first run — ~500 MB).

### Steps

```bash
# 1. Unzip
unzip placebo-client.zip
cd placebo-client

# 2. Build (Linux/macOS)
./gradlew build

# 2. Build (Windows)
gradlew.bat build
```

First run downloads ~500 MB and may take 3–5 minutes. Subsequent builds are much faster.

When it finishes, your mod jar will be at:

```
build/libs/placebo-client-1.0.0.jar
```

### Install

1. Install **Fabric Loader 0.19.3+** for Minecraft 26.2 (use the [Fabric installer](https://fabricmc.net/use/))
2. Drop these jars into `.minecraft/mods/`:
   - `fabric-api-*.jar` ([download](https://modrinth.com/mod/fabric-api))
   - `fabric-language-kotlin-*.jar` ([download](https://modrinth.com/mod/fabric-language-kotlin))
   - `placebo-client-1.0.0.jar` (the one you just built)
3. Launch Minecraft with the Fabric profile

### Open the ClickGUI

In-game, press **RIGHT-SHIFT**. Rebindable under **Options → Controls → Placebo Client**.

## Troubleshooting

### "Could not find method modImplementation()" / "Could not find method api()"

This means Loom didn't load. Make sure:
1. You're using JDK 25 (not 21 or 17) — check `java -version`
2. `JAVA_HOME` points at the JDK 25 install
3. The `gradle/wrapper/gradle-wrapper.properties` file says `gradle-9.6.1-bin.zip`
4. You're running `./gradlew build` (not a system-wide `gradle build` — system gradle is often a different version)

### Build still fails

Run with `--stacktrace` and look at the "Caused by:" line near the bottom of the error — that's the actual problem:

```bash
./gradlew build --refresh-dependencies --stacktrace
```
